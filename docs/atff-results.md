# ATFF 实测结果（真机 SWD 只读采集）

本目录的图全部来自真机 TOP（小陀螺）稳态采集，固件为 `ATFF` 版（v7，`2026-10-26_top_ff_adapt4`）。
采集方式：SWD 只读 attach（不写内存、不 halt、不下发电机力），底盘自转约 7.0 rad/s，
误差 `e = set - actual` 由固件外环 PID 直接给出。

|---|---|
| rms | 0.123° |
| sigma | 0.123° |

### fig_entry_transient.png

从「中档静止」一路采到「切上档」的高速采集（174 Hz），t=0 为 gmode 首次变 1：
进 TOP 前 1 s 内 max abs 由 4.42° 降到 2.32°（-47%）、首秒 rms 由 1.64° 降到 1.10°（-33%）。
注：误差包络回到 0.5° 以内的时刻 v6 约 1.56 s、ATFF 约 1.98 s（软启动让尾巴略长），
这两个指标不要与「自适应系数收敛时间」混用。

### fig_spectrum.png

误差谱（自转 vs 中档静止对照）。三条要点：

1. 锁相（1x~6x）幅值均已 < 0.007°，锁相只占方差 0.3% —— 已被 ATFF 压掉；
2. 40.4 Hz 只在自转时出现（35~48 Hz 频段 rms：自转 0.062° vs 静止 0.0002°，约 5 个数量级），
   且两次不同自转转速下滚子率由 35.6 Hz 变到 39.7 Hz 而谱峰始终钉在 40.3~40.5 Hz
   —— 属机械结构固有模态被滚子接地冲击激起，不是环路自激、也不是滚子率受迫；
3. 环路带宽约 1.7 Hz，对 40 Hz 没有控制权限，前馈/增益/陷波都不能消除物理振动，只能机械处理。

## 残余构成（当前最大项）

| 频段 | rms | 说明 |
|---|---|---|
| 0.3~0.8 Hz | 0.017° | |
| 0.8~1.5 Hz | 0.055° | |
| 1.5~3.0 Hz | 0.066° | 最大分频段 |
| 3.0~6.0 Hz | 0.043° | |
| 6.0~12 Hz | 0.039° | |
| 12~20 Hz | 0.022° | 174 Hz 高速段 |
| 20~40 Hz | 0.033° | 174 Hz 高速段 |
| 40~48 Hz | 0.040° | 40.4 Hz 结构峰，约 11% 方差 |

0.8~6 Hz 三根按功率合成约 0.096° rms（约占方差六成），是当前最大的残余块；
40.4 Hz 是最强的单个离散峰，但不是最大残余块。

注：0.3~20 Hz 取 47 s 稳态采集；20~48 Hz 取 174 Hz 高速段（剔除切档瞬态 2 s），
因为 51.8 Hz 采样的 Nyquist 只有 25.9 Hz。频段 rms 对窗长/窗函数敏感（约 ±30%），引用时按量级理解。
